# NexaNav — Interactive Navigation Experience

SkillCraft Web Development Internship Project

## Objective
Create an interactive navigation menu that:
- stays fixed and visible on every page
- changes style when the user scrolls
- provides visual feedback when hovering over menu items
- works across desktop and mobile
- includes a clear active-page state

## Extra enhancements
- Scroll progress indicator
- Glassmorphism header
- Animated hover underline
- Mobile hamburger menu
- Dark/light theme toggle
- Reveal-on-scroll animations
- Multi-page structure
- Demo contact form
- Responsive layout

## Files
- index.html — Home
- about.html — About
- features.html — Feature explanation
- contact.html — Demo/contact page
- css/style.css — Complete styling
- js/script.js — Interactions

## How to run
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For the best development experience, open the folder in VS Code and use Live Server.

No Node.js, database, or framework is required.

## Implementation flow
1. HTML creates the fixed navigation and page sections.
2. CSS creates the visual design, hover states and responsive layout.
3. JavaScript adds the scroll state to the header.
4. JavaScript calculates the scroll-progress bar.
5. JavaScript controls the mobile menu.
6. JavaScript stores the selected theme in localStorage.
