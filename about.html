ABOUT THE PROJECT

Designed to make navigation memorable.

NexaNav is a front-end implementation of an interactive fixed navigation menu, created for the SkillCraft Web Development internship task.

THE BRIEF

One menu, multiple states.

The core requirement is simple: create a navigation menu that stays fixed and changes its visual style when users hover over menu items or scroll the page.

This implementation expands that brief into a polished multi-page experience without adding unnecessary frameworks.

01Initial stateTransparent glass header with subtle border.
02Hover stateAnimated underline, glow and lift feedback.
03Scrolled stateCompact blurred background and stronger shadow.
04Mobile stateAnimated hamburger menu with accessible controls.

“Good navigation should disappear into the experience — until you need it.”
